## 2. 企业定位与核心价值

奥飞新材定位于气凝胶材料及其复合产品的技术转化和产业化应用，核心目标是通过新材料技术推动节能减排、热管理与绿色低碳发展。

企业价值主张：

```text
以气凝胶为核心功能材料，
通过低成本制备、复合产品开发和跨行业应用，
为建筑、新能源、数据中心、工业设备等场景提供节能隔热与热管理解决方案。
```

官网希望呈现的企业形象：

- 科技型新材料企业；
- 依托高校科研平台；
- 具备产学研协同能力；
- 具备中试转化和产业化能力；
- 关注绿色建筑、节能减排和热管理；
- 能与产业链上下游企业开展联合研发与合作；
- 兼具技术研发能力与市场应用能力。

## 3. 科研与产学研背景

公司依托中南大学相关科研力量，与中南奥飞气凝胶研究院等平台开展合作。

- 常压干燥气凝胶制备技术；
- 低成本气凝胶粉体量产技术；
- 透明气凝胶技术；
- 水性气凝胶涂料技术；
- 金属气凝胶技术；
- 气凝胶复合材料技术；
- 无机保温涂料技术；
- 气凝胶在多行业中的复合应用开发。

## 19. 旧域名迁移

```text
alfy.cn/*
www.alfy.cn/*
→ 301
www.alfy.com.cn/*
```

迁移要求：

- 保留旧域名控制权；
- 旧域名证书持续有效；
- 301 至少保留 6～12 个月，最好长期保留；
- 整理旧 URL 到新 URL 的映射；
- 避免大量旧链接进入 404；
- 迁移前后提交 sitemap 并观察抓取。


## 24. 部署架构

```text
ECS：2 核 4G 起步，预算允许可使用 4 核 8G
系统：Ubuntu 22.04 或 Alibaba Cloud Linux
硬盘：40G～80G
带宽：3M～5M
数据库：MySQL 8 或阿里云 RDS
对象存储：后续可接 OSS
```

部署结构：

```text
Nginx
├── www.alfy.com.cn   → Nuxt
├── admin.alfy.com.cn → Vben 静态资源
├── api.alfy.com.cn   → Spring Boot
└── alfy.cn           → 301 到新域名
```

服务器目录建议：

```text
/var/www/alfy/web
/var/www/alfy/admin
/opt/alfy-api
/data/alfy/uploads
/data/alfy/logs
/data/alfy/backup
```

## 25. Docker 策略

第一版不强制使用 Docker。

推荐一期：

```text
Nginx 直接安装
Spring Boot 使用 systemd
Nuxt 使用 PM2 或 Node 服务
Vben 打包为静态资源
MySQL 使用 RDS 或直接安装
```

但应预留 Docker 化能力：

- 配置使用环境变量；
- 上传文件和日志使用独立目录；
- 数据库脚本纳入版本管理；
- API 地址不写死；
- Nginx 配置归档；
- 路径不硬编码。

## 26. 安全原则

### 服务器

- 只开放 80、443 和受限的 22；
- 不开放 MySQL、Redis、Spring Boot 和 Nuxt 内部端口；
- 使用强密码；
- 限制 SSH 来源；
- 定期更新系统；
- 使用 HTTPS。

### 后台

- 密码哈希存储；
- 登录错误次数限制；
- token 过期；
- 后台接口鉴权；
- 角色权限；
- 操作日志；
- 默认管理员密码必须修改。

### 文件与表单

- 文件类型、MIME、大小限制；
- 随机文件名；
- 上传目录禁止执行；
- 验证码；
- IP 限流；
- 重复提交限制；
- 日志中不记录密码和密钥。

## 29. 内容真实性与保密要求

```text
不得编造企业参数、案例、客户、专利、认证、报价和合作关系；

AI 不得访问或回答企业内部敏感内容。
```

## 30. 对 AI 编码工具的通用要求

将本文件交给 ChatGPT、Codex 或其他 AI 后，应要求其：

```text
先理解企业和网站目标，再处理代码；
保持技术路线一致；
避免过度设计；
不要擅自引入大量新框架；
数据库结构变化使用迁移脚本；
不泄露或硬编码密码、密钥和 Webhook；
不直接操作生产数据库；
重要功能增加测试；
修改前先阅读现有项目；
不修改与当前任务无关的文件；
对不明确需求先提出问题，不擅自补全业务事实。
```
