## 1. 项目一句话说明

为湖南奥飞新材料有限公司重构企业官网：以 **Nuxt 3 官网 + Vben Admin 后台 + Spring Boot 3 API + MySQL/Flyway** 建设一个可维护、SEO 友好、可发布内容并可扩展的企业网站。

旧站为 WordPress，旧域名为 `alfy.cn`、`www.alfy.cn`；规划新官网域名为 `www.alfy.com.cn`。旧域名上线后需要做 301 迁移，但尚未实施。

## 6. 已实现的文章与媒体接口

公开接口统一响应格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

当前已实现：

| 接口 | 行为 |
| --- | --- |
| `GET /api/v1/health` | 服务健康检查 |
| `GET /api/v1/public/article-categories` | 返回文章分类树 |
| `GET /api/v1/public/articles?category=&page=1&size=10` | 返回**已发布**文章分页；`news` 自动覆盖两个新闻子分类 |
| `GET /api/v1/public/articles/{articleId}` | 返回**已发布**文章详情 |
| `GET /api/v1/public/media/{mediaId}` | 仅返回至少关联到一篇已发布文章的媒体文件 |

关键安全规则：文章与媒体读取服务固定过滤 `PUBLISHED`。当前草稿文章/草稿媒体请求均返回 404；文章详情中的已关联图片会改写为受控媒体接口地址。

详细字段与示例见 `docs/文章前台读取接口草案.md`。该文档是当前可供前端讨论的草案，并非全部官网模块的最终 API 合同。

## 8. 当前关键决策与未决事项

### 已决定

- 旧站所有已纳入内容统一建模为文章，不再将案例、研发成果、应用技术拆成独立表；
- 一篇文章可以属于多个分类；
- 历史内容先以草稿入库；
- `新建文件夹` 暂不处理；
- 未对接页面前，公开接口不得输出草稿；
- 本地文件先使用本地存储，保留迁移 OSS 的空间。

### 尚未决定，不能擅自定稿

- 官网首页 PDF 的各模块是否动态配置、哪些内容由后台维护；
- 产品、应用、合作伙伴、询盘、单页等模块的字段与优先级；
- 管理员鉴权采用 Sa-Token 还是 Spring Security + JWT；
- 一期角色是否只用 `super_admin` / `content_admin`，还是建立 RBAC；
- 富文本编辑器和 HTML 安全清洗策略；
- 文章 slug 规则、改名后的重定向策略；
- 封面图选择规则、媒体上传限制、是否直接接入阿里云 OSS；
- 首页推荐机制（自动聚合、文章推荐标记，或单独首页区块配置）；
- 企业微信通知是否纳入一期；
- 最终产品参数、公开案例、联系信息和资料版权确认。

## 9. 下一阶段：以首页 PDF 收敛 API 契约

公司已完成官网首页展示效果的 PDF 原型。PDF 提供后，下一位 Codex 应按以下顺序工作：

1. 阅读 PDF，逐屏列出模块、字段、图片比例、交互和跳转目标；
2. 将每个模块标记为：静态文案、后台可编辑单页、列表聚合、独立业务实体或表单；
3. 与前端同门确认每个模块的请求时机、返回字段、空状态、加载状态、移动端差异和 URL；
4. 新建并共同维护 `docs/api-contract.md`，冻结第一版接口合同；
5. 仅在接口合同确认后，设计新的 Flyway 迁移和后端 API；
6. 优先实现“后台创建/编辑/发布文章 → 官网列表/详情显示 → 下线后隐藏”的新闻完整闭环；
7. 再按首页真实需要依次实现 Banner、产品、案例/应用、合作伙伴、单页和询盘。

建议首页接口不要过早写死为一个巨型接口。只有在原型确认后，才判断采用：

```text
多个领域接口由前端组合
或
/api/v1/home 聚合接口 + 可复用的领域接口
```

无论采用哪种方式，首页的内容来源、排序、推荐标记、缓存策略和后台维护入口都必须写进接口合同。
