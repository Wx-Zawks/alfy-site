# 文章前台读取接口草案

本文档对应当前已实现的只读接口，供 Nuxt 前端先行对接。所有响应采用：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

只有状态为 `PUBLISHED` 的文章和其关联媒体会通过这些接口返回；当前已导入的历史内容均为 `DRAFT`，因此文章列表暂为空是预期行为。

## 获取分类树

`GET /api/v1/public/article-categories`

返回根分类及其子分类。新闻动态为根分类，包含公司新闻和行业新闻。

```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "code": "news",
      "name": "新闻动态",
      "sortOrder": 10,
      "children": [
        { "id": 2, "code": "company_news", "name": "公司新闻", "sortOrder": 11, "children": [] },
        { "id": 3, "code": "industry_news", "name": "行业新闻", "sortOrder": 12, "children": [] }
      ]
    }
  ]
}
```

## 获取文章列表

`GET /api/v1/public/articles`

查询参数：

- `category`：可选分类编码，例如 `news`、`company_news`、`industry_news`、`case`、`research`、`application_technology`。传 `news` 时包含两个新闻子分类。
- `page`：页码，默认 `1`。
- `size`：每页数量，默认 `10`，最大 `100`。

返回的 `data` 为：

```json
{
  "records": [
    {
      "id": 101,
      "title": "文章标题",
      "summary": "文章摘要",
      "coverUrl": null,
      "sourcePublishedAt": "2025-06-28T10:00:00",
      "publishedAt": "2026-07-16T09:00:00",
      "categories": [
        { "id": 2, "code": "company_news", "name": "公司新闻", "sortOrder": 11, "children": [] }
      ]
    }
  ],
  "total": 1,
  "page": 1,
  "size": 10
}
```

`sourcePublishedAt` 是旧站原发布时间；`publishedAt` 是新站的正式发布时间。页面展示日期建议优先使用 `publishedAt`，未设置时再使用 `sourcePublishedAt`。

## 获取文章详情

`GET /api/v1/public/articles/{articleId}`

详情额外包含 `contentHtml`、`sourceUrl` 和 `media`。正文中已关联图片的 `src` 会自动替换为媒体接口地址，前端可在经过自身安全策略处理后直接渲染正文 HTML。

```json
{
  "id": 101,
  "title": "文章标题",
  "contentHtml": "<p>正文</p><figure><img src=\"/api/v1/public/media/88\" alt=\"配图\"></figure>",
  "sourceUrl": "https://www.alfy.cn/...",
  "media": [
    {
      "id": 88,
      "mediaType": "IMAGE",
      "originalFilename": "image.jpg",
      "mimeType": "image/jpeg",
      "usageType": "INLINE",
      "url": "/api/v1/public/media/88",
      "caption": null,
      "sortOrder": 1
    }
  ]
}
```

## 获取媒体文件

`GET /api/v1/public/media/{mediaId}`

返回文件二进制内容。媒体必须至少被一篇已发布文章关联；草稿文章的图片和视频即使已存入服务器，也会返回 `404`。

## 当前未开放的管理能力

文章新建、编辑、审核、发布、下线、媒体上传等写接口尚未开放。它们需要先纳入管理员登录、角色权限和操作审计，避免在鉴权缺失时暴露写入能力。
