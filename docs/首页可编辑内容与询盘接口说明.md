# 首页可编辑内容与询盘接口说明

适用版本：后端数据库迁移 V11。本文供 `alfy-web` 与 `alfy-admin` 联调使用；所有响应均包裹为 `{ "code": 0, "message": "success", "data": ... }`。

## 1. 内容发布规则

- Banner、技术研发内容、应用场景、案例和新闻均先保存为草稿，只有发布后才会由公开接口返回。
- Banner 的 `startsAt`、`endsAt` 为可选展示窗口；当前时间未到或已结束时，轮播及其图片均不公开。
- 首页新闻只读取已发布且配置了 `homeSlot` 的文章；应用场景、案例沿用现有 `isFeatured`、`sortOrder` 配置。
- 素材先上传取得 `id`，再将该 ID 填入 `desktopMediaId`、`mobileMediaId`、`coverMediaId` 等字段。公开媒体 URL 仅在被已发布内容引用后可读取。

## 2. 公开接口

### 首页聚合

`GET /api/v1/public/home`

一次返回首页动态模块：

```json
{
  "banners": [],
  "applicationScenes": [],
  "featuredCases": [],
  "technologyOverview": null,
  "featuredArticles": []
}
```

当模块没有已发布内容时返回空数组或 `null`，前端应隐藏对应模块或展示“内容建设中”，不得回退到未获授权的 mock 素材。

### 独立读取

- `GET /api/v1/public/hero-slides`
- `GET /api/v1/public/pages/technology`
- `POST /api/v1/public/inquiries`

询盘请求示例：

```json
{
  "name": "张三",
  "company": "某公司",
  "phone": "13800000000",
  "email": "name@example.com",
  "inquiryType": "PROJECT_SOLUTION",
  "message": "希望获取项目方案",
  "productId": null,
  "sourceUrl": "https://www.example.com/products",
  "utm": { "source": "baidu" },
  "privacyAccepted": true
}
```

`phone` 与 `email` 至少填一项。成功响应为 `{ "inquiryNo": "AF..." }`。当前实现已完成字段校验、隐私同意校验与后台查询；生产上线前仍需在网关或 WAF 配置 IP 限流、验证码和敏感词策略。

## 3. 管理端接口

所有接口均需 `Authorization: Bearer {accessToken}`。

| 模块 | 接口 |
| --- | --- |
| 素材库 | `GET /api/v1/admin/media`、`POST /api/v1/admin/media`（`multipart/form-data`，文件字段为 `file`，可选 `altText`） |
| 首页固定区块 | `GET/POST /api/v1/admin/home-sections`、`GET/PUT/DELETE /api/v1/admin/home-sections/{id}`；官网读取 `GET /api/v1/public/home-sections` |
| 首页轮播 | `GET/POST /api/v1/admin/banners`、`GET/PUT/DELETE /api/v1/admin/banners/{id}`、`POST /api/v1/admin/banners/{id}/publish`、`POST /api/v1/admin/banners/{id}/offline` |
| 技术研发 | `GET/PUT /api/v1/admin/technologies`、`POST /api/v1/admin/technologies/publish`、`POST /api/v1/admin/technologies/offline` |
| 询盘 | `GET /api/v1/admin/inquiries?status=&keyword=&page=1&size=20`、`GET /api/v1/admin/inquiries/{id}`、`PUT /api/v1/admin/inquiries/{id}` |
| 已有内容 | 应用场景 `/admin/application-scenes`、案例 `/admin/cases`、新闻 `/admin/articles`，继续沿用现有 CRUD、发布和下线接口 |
| 单页首屏 | `GET/POST /api/v1/admin/page-heroes`、`GET/PUT/DELETE /api/v1/admin/page-heroes/{id}`、`POST /api/v1/admin/page-heroes/{id}/publish`、`POST /api/v1/admin/page-heroes/{id}/offline` |
| 顶部/页脚导航 | `GET /api/v1/admin/navigations?area=HEADER|FOOTER`、`POST /api/v1/admin/navigations`、`GET/PUT/DELETE /api/v1/admin/navigations/{id}` |
| 站点信息 | `GET/PUT /api/v1/admin/site-settings`（Logo、联系信息、二维码、备案、隐私政策） |
| 合作伙伴 | `GET/POST /api/v1/admin/partners`、`GET/PUT/DELETE /api/v1/admin/partners/{id}`、`POST /api/v1/admin/partners/{id}/publish`、`POST /api/v1/admin/partners/{id}/offline` |
| 可编辑单页 | `GET/POST /api/v1/admin/pages`、`GET/PUT/DELETE /api/v1/admin/pages/{id}`、`POST /api/v1/admin/pages/{id}/publish`、`POST /api/v1/admin/pages/{id}/offline` |
| 旧址重定向 | `GET/POST /api/v1/admin/redirects`、`GET/PUT/DELETE /api/v1/admin/redirects/{id}` |

### Banner 保存示例

```json
{
  "eyebrow": "战略合作",
  "title": "以新材料之力",
  "highlightText": "服务“双碳”战略",
  "summary": "轮播摘要",
  "desktopMediaId": 101,
  "mobileMediaId": 102,
  "primaryActionLabel": "了解核心技术",
  "primaryActionTarget": "/technology",
  "secondaryActionLabel": "获取方案",
  "secondaryActionTarget": "#inquiry",
  "sortOrder": 1,
  "startsAt": null,
  "endsAt": null,
  "version": 0
}
```

创建时不传 `version`；编辑时必须传详情响应的 `version`，并处理 HTTP 409 冲突。

### 技术研发保存示例

`capabilityRows` 与 `pillars` 是 JSON 数组，由管理端按页面固定字段编辑，避免前台解析任意 HTML：

```json
{
  "eyebrow": "技术研发",
  "title": "新一代常压",
  "highlightText": "干燥技术",
  "summary": "经企业审核后公开的技术能力简介。",
  "ctaLabel": "进入技术中心",
  "ctaTarget": "/technology",
  "capabilityRows": [{ "direction": "材料制备", "stage": "PILOT_VALIDATION", "action": "技术咨询" }],
  "pillars": [{ "title": "粉体与颗粒", "summary": "经审核后公开的说明。", "target": "/technology" }],
  "contentHtml": "<p>技术页面正文</p>",
  "version": 0
}
```

### 询盘跟进示例

```json
{
  "status": "CONTACTED",
  "adminNote": "已联系客户，等待补充工况参数。"
}
```

允许状态：`NEW`、`CONTACTED`、`QUALIFIED`、`CLOSED`、`SPAM`。

## 5. 单页首屏、导航与页脚

截图中的单页上方首屏由 `page_hero` 管理，适用于 `about`、`technology`、`cooperation`、`products`、`applications`、`news` 等稳定页面标识。可编辑字段包括：`eyebrow`、`title`、`highlightText`、`summary`、桌面/移动背景图，以及两个 CTA。发布后前端读取：

```text
GET /api/v1/public/pages/{pageKey}/hero
```

合作伙伴公开列表为 `GET /api/v1/public/partners`；可编辑单页正文为
`GET /api/v1/public/pages/{pageKey}`。两类公开接口均只返回已发布内容。

顶部与页脚导航的公开接口为 `GET /api/v1/public/navigation`，返回 `{ "header": [], "footer": [] }` 树结构；站点 Logo、联系信息和页脚内容由 `GET /api/v1/public/site` 返回。未启用导航和未发布首屏不得在前端展示。

单页首屏保存示例：

```json
{
  "pageKey": "technology",
  "eyebrow": "核心技术",
  "title": "中南大学气凝胶成果转化核心平台",
  "highlightText": null,
  "summary": "经企业审核后公开的简介。",
  "backgroundMediaId": 101,
  "mobileBackgroundMediaId": 102,
  "primaryActionLabel": "获取方案",
  "primaryActionTarget": "#inquiry",
  "secondaryActionLabel": null,
  "secondaryActionTarget": null,
  "version": 0
}
```

## 4. 运行配置

`ALFY_CONTENT_STORAGE_ROOT` 指定本地素材存储目录。`ALFY_WEB_ALLOWED_ORIGINS` 指定可调用 API 的官网和管理端域名，多个地址以英文逗号分隔；默认允许本地 `3000` 与 `5173` 端口，生产部署必须替换为正式域名。
